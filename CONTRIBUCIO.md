# Com contribuir

## Flux de treball

1. Crea una branca descriptiva: `git checkout -b feat/nom-funcionalitat`
2. Fes commits petits i amb missatges clars.
3. Puja la branca i obre una pull request cap a `main`.
4. Espera la revisió abans de fusionar.

## Coautoria

Quan treballeu en parella, afegiu el company com a coautor al commit.
